KAi:----

KAi is a simple terminal-based AI assistant made with Python.

This project was created as a learning project to explore:

- Python programming
- File handling
- Randomization
- Terminal interaction
- Basic assistant systems

---

Features 🚀

- Coin toss
- Date and time
- Word ↔ Binary converter
- Simple calculator
- YouTube video downloader
- Rock paper scissors game
- Persistent memory system
- Random responses
- Command-based interaction

---

Commands 📜

Command| Description
"/help"| Show commands
"/date"| Show current date
"/time"| Show current time
"/toss"| Toss a coin
"/sum"| Calculator
"/w_t_b"| Word to binary
"/b_t_w"| Binary to word
"/calculate_death"| Fake random death calculator
"/ytd"| Download YouTube videos
"_cv"| Show current version

---

Installation ⚙️

Clone the repository:

git clone YOUR_REPO_LINK

Install requirements:

pip install yt-dlp

Run the program:

python main.py

---

Requirements 📦

- Python 3
- yt-dlp
